# Resume Analyzer

A Python-based Resume Analyzer that extracts key information such as name, email, skills, experience, and more from resumes (PDF/DOCX).

---

## 🚀 Features

- Extract Name
- Extract Email
- Extract Phone Number
- Extract Skills
- Extract Experience
- Extract College Name
- Extract Designation
- Extract Company Names

---

## 🛠️ Tech Stack

- Python
- spaCy (NLP)
- NLTK
- PDFMiner
- docx2txt

---

## ⚙️ Installation

```bash
git clone https://github.com/khushi-0-1/ResumeParser.git
cd ResumeParser
```
### Create virtual environment:
```bash
python -m venv venv
venv\Scripts\activate
```
### Install dependencies:
```bash
pip install -r requirements.txt
```
---

## ▶️ Usage
Run the parser:
```bash
python -m Resume_Analyzer.command_line -f sample_resume.pdf
```
